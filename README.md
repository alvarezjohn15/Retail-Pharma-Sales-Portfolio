# Retail-Pharma-Project
#### Sales • Transactions • Target Profit
## 📌 Overview
#### This repository is from an AI Generated dataset of Franchise Pharmacy stores containing 7,000+ transactions from January 2024 until May 2026. 
## 📂 Dataset Description
#### The dataset simulates close to real sales transaction from a retail pharmacy store.
#### • Number of Stores : 6
#### • Number of Transactions : 7,000 +
#### • Product Catalog Size : 100
#### •	Duration : Jan2024- May2026
## 🛠️ Tools
#### Power BI – Interactive data visualizations for insights and reporting
## ⚠️ Problem Statement
#### 15% of the overall sales of Php 9.27M was set to be achieved by the end of 2026.
